# BeeCrowd Python Solutions

This repository contains my accepted solutions to programming problems from BeeCrowd (formerly URI Online Judge), implemented in Python.

As an Electrical and Electronic Engineering (EEE) student with a strong interest in Machine Learning and Artificial Intelligence, I use problem-solving platforms like BeeCrowd to strengthen my programming fundamentals and analytical thinking skills.

Through these exercises, I practice:

* Problem-solving and logical reasoning
* Algorithmic thinking
* Python programming
* Data structures and basic algorithms
* Writing clean and efficient code

These skills form an important foundation for software development, data science, and machine learning projects.
